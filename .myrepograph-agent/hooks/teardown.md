# Teardown Hook

Run before ending a session.

1. Mark completed items in `memory/runtime/context.md`; leave unfinished ones
   open with a note on where they stand.
2. Append a close-out to `memory/runtime/dailylog.md`: what changed, what was
   verified and how, and what is still outstanding.
3. Record surprises — a wrong assumption caught late is the highest-value
   thing to write down.
4. Leave the workspace building and its tests passing, or say plainly that
   you did not.
