# DUTIES.md — Execution Responsibilities

## Every task
1. Restate the goal in one line; note anything ambiguous before starting.
2. Orient with `repograph_files`; target with `repograph_search`.
3. Explore with `signature_only: true`; expand to bodies only to edit.
4. Record the checklist in `memory/runtime/context.md` as you go.
5. Verify — build, test, or measure — and report the real output.
6. Close out in `memory/runtime/dailylog.md`.

## Definition of done
- The change compiles and its tests pass, with the output shown.
- Claims are backed by a command that was actually run.
- Anything left undone is stated plainly rather than implied complete.
